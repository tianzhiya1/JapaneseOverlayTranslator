# 日语悬浮翻译器 Android v0.6

## 用户操作

首次打开 App，只在安卓提示时授予麦克风和悬浮窗权限。App 会自动启动日语离线语音识别并尝试翻译为中文。

- **听音字幕**：屏幕底部仅显示中文；不再铺满日文识别过程。字幕保留约 7.5 秒，新的翻译会更新字幕。
- **长按悬浮「译」按钮**：请求一次系统无障碍截图，进入截图选区。可拖动框选日文/英文文字，也可点按目标让软件自动取附近文字；完成后仅显示中文翻译约 13 秒。
- **短按悬浮「译」按钮**：隐藏/显示字幕。可拖动按钮移动位置。

截图功能必须**手动在安卓设置里启用 App 的无障碍服务**，这是系统规定，一次授权后无需每次重复。需要 Android 11 以上，受保护的内容可能无法截图。

## 改动和局限

- ASR 使用离线 Vosk 日语模型，不依赖搜狗或 Google 语音服务；可能无法直接捕获 YouTube App 内部音频，目前仍依靠麦克风。
- 日语 ASR 产出的词间空格会进行规范化后再送入翻译引擎；限速约每 2.4 秒尝试一次提前翻译，正式语音分段也会翻译。当前仅允许一个翻译任务正在执行，后续翻译合并为最新请求；主要为了缓解卡顿与严重延迟。
- 中文翻译当前仍是 ML Kit 日→中、英→中离线模型。**其语言表达质量没有经过实机验证，也不能保证高于 v0.5。** 如果识别的日语很准但翻译不佳，需要继续评估更强的翻译模型或可自托管的开源翻译后端，不能单凭隐藏日文解决。
- 截图 OCR 使用 ML Kit 16.0.1 本地日文/拉丁文字识别。截图仅在手动长按之后进行，处理在本机；部分受保护 App 不允许截图。
- 初次需要联网下载翻译模型。内置日语 ASR 模型约数十 MB，APK 较大。长时间识别仍可能导致电量和 CPU 消耗，已降低识别线程优先级以保护 UI，但没有实机性能保证。

## 构建

Actions → Build Android APK → 最新成功的 workflow → Artifacts: JapaneseOverlayTranslator-v0.6-chinese-ocr-apk。

FloatingService 负责麦克风识别、翻译与悬浮 UI；TranslateAccessibilityService 只响应用户长按发起的截图；ScreenshotSelectionActivity 负责框选与 OCR。
